# 健康饮食管理端

独立于用户端运行的本地管理后台，默认连接 `C:\Users\czy08\Desktop\v2\health.db`。

## 当前功能

- 首次启动创建超级管理员
- 管理员登录、失败次数限制与 CSRF 防护
- 用户、监督关系、饮食记录和食物库管理
- 管理员敏感操作审计日志
- 用户端数据库与管理员数据库分离

## 数据文件

- `admin.db`：管理员账户和审计日志，首次启动自动创建
- 用户数据：读取桌面 `v2\health.db`

## 启动

双击 `启动管理端.bat`，浏览器会打开 `http://127.0.0.1:5100`。

首次进入时请创建超级管理员。管理员密码至少 10 位，并包含大小写字母和数字。
