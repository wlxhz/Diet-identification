# 健康饮食管理端

独立于用户端运行的本地管理后台。规范启动方式和数据路径见当前目录的 `README.md` 及仓库级文档。

## 当前功能

- 首次启动创建超级管理员
- 管理员登录、失败次数限制与 CSRF 防护
- 用户、监督关系、饮食记录和食物库管理
- 管理员敏感操作审计日志
- 用户端数据库与管理员数据库分离

## 数据文件

- `admin.db`：管理员账户和审计日志，首次启动自动创建
- 用户数据：默认读取 `.workspace/data/user-web/health.db`

## 启动

推荐从仓库根目录运行 `scripts/dev/start-supervisor-web.ps1`，浏览器打开 `http://127.0.0.1:5100`。

首次进入时请创建超级管理员。管理员密码至少 10 位，并包含大小写字母和数字。
